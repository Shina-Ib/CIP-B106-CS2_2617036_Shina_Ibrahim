# Android 10 Pixel 3 Evidence Case Study
**Overview**
This project examines an authorised Google Pixel 3 Android 10 training logical copy to identify digital artefacts and reconstruct relevant device activity. The investigation focuses on system settings, user and account information, installed applications, communications, media, and location-related records.

**Objectives**
1. Examine device configuration, accounts, and connectivity.
2. Analyse application metadata and usage records.
3. Investigate messages, contacts, call logs, and calendar data.
4. Examine Google applications and third-party apps, including Kik, TextNow, and WhatsApp, where available.
5. Reconstruct a timeline using corroborated evidence.
6. Document findings, limitations, and conclusions.
   
**Tools and Methods**
1. DB Browser for SQLite
2. XML and protocol buffer parsers
3. Approved digital forensic tools
4. Manual artefact verification and timestamp analysis
   
**Evidence Scope**
The supplied evidence is a logical copy acquired after TWRP root access, not a bit-for-bit physical image. Missing, inaccessible, or encrypted artefacts are documented where applicable. The acquisition process does not prove that the original device user rooted the phone.

**Forensic Principles**
1. Preserve evidence integrity and work from a verified copy.
2. Document source paths, raw values, timestamps, and tools.
3. Corroborate findings using independent artefact sources.
4. Distinguish verified facts from inferences.
5. Protect sensitive information and avoid unsupported conclusions.
   
**Limitations**
The logical copy may not contain all original device data. Application activity does not independently identify the person using the device, and location artefacts do not automatically prove physical presence.

**Conclusion**
This case study demonstrates Android mobile forensic techniques for examining digital artefacts, correlating records, and reconstructing a defensible activity timeline while maintaining evidence integrity and professional standards.
